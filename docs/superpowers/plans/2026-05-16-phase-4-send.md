# Phase 4: Clipboard Send-back — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the `clipboard:write-geared` IPC channel + replace every "Send..." button in the renderer with the corresponding "Copy..." action. After Phase 4, the full v2 round-trip works end-to-end: Capture from clipboard → edit → Gear → review/edit geared → Copy to clipboard → paste into the user's terminal.

**Architecture:** Extend the existing `ClipboardHandler` (Phase 3) with a write path that calls `clipboard.writeText(text)` and emits `send-copied` / `send-write-failed` log events through the existing `clipboard` Logger category. Renderer-side: replace ActionsRow's "Send" button with "Copy Geared" (disabled until a gear pass has run, matching spec §5) and replace GearReviewPane's "Send original" + "Send geared" buttons with "Copy original" + "Copy geared". On click, write the text to the OS clipboard, fire a success toast ("Geared prompt copied — paste into your terminal."), and clear composer state (prompt + draft + gear pane). The user pastes themselves with Ctrl+V; no automation in v2.0.

**Tech Stack:** TypeScript 5 strict, Electron 32 (`clipboard.writeText`), electron-vite 2, React 18, Vitest 2, Playwright 1.45.

**Branch:** All work happens on `v2/headless`. Phase exit is annotated tag `v2.0.0-phase-4-send`.

## Design decisions captured during planning

| Decision | Choice | Why |
|---|---|---|
| Reuse vs. new IPC class | Reuse Phase 3's `ClipboardHandler` — add a second `handle()` registration | Same surface (clipboard), same Logger category. One handler class, two channels. |
| Failure-shape pattern | Custom union `{ ok: true } \| { ok: false, code: 'WRITE_FAILED' }` matching the Phase 3 `clipboard:read-prompt` pattern | Phase 3 already deviated from the project's `IpcError`-wrapped pattern. Stay consistent within `clipboard`. Phase 6 may refactor both. |
| Success toast severity | `info` (not the `success` severity if one exists; spec only describes the *message*) | The action completed; user benefits from confirmation. Phase 6 may add a dedicated success severity. |
| Where Copy Geared lives | In BOTH ActionsRow (disabled when `gearState === null`) AND inside GearReviewPane (as "Copy original" + "Copy geared", replacing the two Send buttons) | Spec §5 keeps Copy Geared in ActionsRow; GearReviewPane is the editing surface where Copy is the obvious finishing move. Phase 5 layout work may unify. |
| State cleanup on success | Clear `prompt`, `setGearState(null)`, `clearDraft()` | Phase 3 already follows this "complete cycle" pattern. Each Capture→Gear→Copy is a discrete cycle per spec §1. |
| State cleanup on failure | Preserve everything; user can retry | Spec §7 — "Geared text remains in TokenLess — try Copy Geared again." |
| Original-vs-geared symmetry | "Copy original" button kept inside GearReviewPane (was "Send original"); ActionsRow only has "Copy Geared" (the canonical action) | Users sometimes prefer the un-geared text — keep that affordance during review. |
| The Composer Send no-op handler from Phase 1 | Deleted (no longer reachable) | Was a stub awaiting Phase 4. Phase 4 replaces it. |
| Button count after Phase 4 | Still 6 in ActionsRow (Send → Copy Geared, unchanged count) | E2E count assertion stays at 6. |

```typescript
private handleWriteGeared(req: ClipboardWriteGearedRequest): ClipboardWriteGearedResult {
  const text = req.text
  if (text.trim().length === 0) {
    this.logger.warn('clipboard', 'send-empty-input', 'writeGeared called with empty text', {
      inputLength: text.length
    })
    return { ok: false, code: 'EMPTY_INPUT' }
  }

  try {
    this.clipboard.writeText(text)
  } catch (err) {
    this.logger.error('clipboard', 'send-write-failed', 'clipboard.writeText() threw', {
      errorString: err instanceof Error ? err.message : String(err),
      textLength: text.length
    })
    return { ok: false, code: 'WRITE_FAILED' }
  }

  this.logger.info('clipboard', 'send-copied', 'geared prompt copied to clipboard', {
    textLength: text.length
  })
  return { ok: true }
}
```

  if (text.trim().length === 0) return

    void clearDraft()
