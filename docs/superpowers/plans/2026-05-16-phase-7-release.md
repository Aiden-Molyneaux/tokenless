## Design decisions

| Decision | Choice | Why |
|---|---|---|
| Version bump | `1.0.0` → `2.0.0` | Breaking architectural change (PTY removed, schema migrated). SemVer major. |
| Merge style | `git merge --no-ff` | Preserves the v2/headless branch as a visible parent in the main history. ADR-044. |
| Tag at merge commit | Yes — `v2.0.0` points at the merge commit on `main` | The tag is the canonical "v2 is on main" marker. |
| Final `v2.0.0` tag signing | Signed if user has GPG configured; annotated otherwise | Phase 0-6 tags were annotated only (no signing); v2.0.0 is the release tag and gets `-s` if available. Fall back to `-a` if signing fails — note in commit message. |
| `release/v1` branch | Untouched | Frozen at `v1.0.0-final` per ADR-044. |
| `package-lock.json` regeneration | Run `npm install` after version bump to refresh the lockfile's `"version"` field | Lockfile is source-controlled; stale `version` in lockfile is a real bug. |

### Task 3: README rewrite

**Files:**
- Modify: `README.md`

The current README opens with "sits between you and Claude... hosts Claude Code in an embedded terminal" — fundamentally wrong for v2. Rewrite section by section.

- [ ] **Step 1: Rewrite the intro**

Replace the current opening:

```markdown
# TokenLess

A Windows-first Electron desktop app that sits between you and Claude. Rewrites prompts via Haiku ("gearing") to reduce token waste, and hosts Claude Code in an embedded terminal.

```

With:

```markdown
# TokenLess

A Windows-first Electron desktop app that helps you write token-efficient prompts to Claude. Capture a prompt from your clipboard, optimize it with Haiku "gearing", copy the geared version back to the clipboard. You run Claude Code in your own terminal — TokenLess sits beside it as a prompt-side gearing tool. Designed for half-screen use (TokenLess on one side, terminal on the other).

See `docs/superpowers/specs/2026-05-16-tokenless-v2-headless-design.md` for the v2 design spec. The v1 spec lives at `docs/superpowers/specs/2026-05-13-tokenless-v1-design.md` for historical reference (v1 hosted Claude Code in an embedded terminal — that approach was abandoned in v2; see ADR-043).

## What's different in v2

- No embedded Claude Code terminal — you run Claude Code (CLI or Desktop) in your own terminal
- Clipboard-based capture/copy flow: select text in your terminal → Ctrl+C → click "Capture" in TokenLess → edit + gear → click "Copy Geared" → Ctrl+V in your terminal
- Lighter footprint — `node-pty`, `xterm.js` gone; only `better-sqlite3` remains as a native dep
- Half-screen friendly — sidebar collapses to an icon strip at narrow widths
```
